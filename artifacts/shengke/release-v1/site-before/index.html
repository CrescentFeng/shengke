少样本克隆与情绪控制

CosyVoice2 与 GPT-SoVITS 支持参考音色克隆。CosyVoice2 探索中性、开心、悲伤与愤怒的原生情绪指令；GPT-SoVITS 提供舒缓语速与停顿试用选项。

项目基于网易实习中的语音模型选型与评测经验展开。

用评测记录每次变化

VITS、Transformer TTS 作为固定音色基线，与两个克隆引擎比较合成质量、实时率及资源占用。四模型分别完成 144 次 CPU 和 144 次 RTX 4090D GPU 正式合成测试，均成功。

四轮试听共 21 份评分，另有节奏调整后的定性反馈，均来自同一位听众，属于 N=1 预评测，不代表多人 MOS 结论。GPU 实测已完成，性能指标不代表音质排名。
