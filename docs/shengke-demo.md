# 声刻五分钟演示稿

本稿展示已实测能力。当前已完成 N=1 八样本自听，已完成四模型 GPU 实测，尚无多人 MOS，不展示预估显存、虚构评分或“音质显著提升”结论。演示前确认四个本地服务均为 ready，使用工作台保存的公开音色。

## 0:00–0:40：问题与素材

“声刻针对通用 TTS 音色固定、表达机械的问题，提供短参考语音克隆和情绪指令。我从语音模型选型经验出发，把模型推理、音频质检和评测接成一条可复现的流程。”

选择 `THCHS-30 · D12_792_5s`。展示来源、五秒时长与逐字稿：“带着诸多疑问迎着和煦的春风我们走访了圆明园遗址。”说明两位公开说话人均有 3、5、10 秒参考，文件未经拉伸或补静音。用户已核对六份素材；D12 的十秒参考中“溅落”按反馈更正为“降落”，该处发音疑点单独记录。

## 0:40–1:40：真实克隆

在“合成工作台”选择 CosyVoice2、中性，输入：“你好，欢迎来到声刻。让每一句话，都有自己的温度。”点击生成，展示等待状态、播放器和下载 WAV。CPU 合成需等待；可使用已保存结果演示，但应明确说明是同模型预先生成的音频。

“模型服务在独立环境运行，成功输出才会发布；取消任务后，迟到的模型结果不会把已取消任务改成成功。”

## 1:40–2:40：音色与情绪对照

进入“对比试听”，用同参考与同目标文本比较 CosyVoice2 中性/开心，或比较 CosyVoice2/GPT-SoVITS 两个克隆引擎。悲伤、愤怒的公开样本已保存在情绪验证目录，可以作为追加对照。

“这里使用模型原生情绪指令，并未把音高或播放速度变化当成情绪控制。实际情绪是否清晰、音色是否保持，需要听众给出评价。”

## 2:40–3:40：四模型取舍

打开 `artifacts/shengke/comparison-cpu/report.md`。四模型各十二条文本、每条三次，一次预热单独保存，共 144 次正式合成成功。说明这次是 Apple M5 Pro 开发机 CPU FP32 测量，并存在开发后台活动。

“VITS 和 Transformer 是固定音色基线，不具备这里的短参考克隆能力。RTF 小于一代表该次推理快于输出音频时长，但不能据此认定自然度更高。RTX 4090D FP32 同样完成 144/144 次正式请求，四模型平均 RTF 分别约 0.509、0.216、0.029、0.377。Torch 显存峰值不等于整卡显存占用，完整口径见验收记录。”

## 3:40–5:00：听评与局限

进入“评测中心”，使用评测编号 `aa3b864b-3131-4e83-9626-6e01380192ac`。填写稳定匿名评测人编号，加载八个盲听样本；先听待评语音，克隆样本再听参考人声，之后才给出实际评分。

自然度：1 很不自然、3 可接受但有明显问题、5 非常自然。音色相似度仅用于克隆模型；情绪匹配度仅用于有情绪目标的样本。在备注中记录漏字、重复、断句、失真或情绪不符。

“当前已完成 8/8 份真实个人评分，属于 N=1 预评测，不称多人 MOS。六份克隆样本相似度均为 5 分，但开心匹配度仅 1 分，中性语音仍有断句和机械感问题。后续已完成 GPU 性能矩阵与多轮节奏迭代；开心强度仍有改进空间。”

补充第二轮实验：“第二轮也已完成八份真实评分。整体降速没有稳定改善自然度；增强开心指令虽然情绪分略升，但自然度下降。因此没有将实验配置设为默认，后续重点改进断句和停顿。这里只比较本轮成对结果，不把相同音频跨轮的评分变化说成算法提升。”

演示结束后可导出实际评分 CSV，不为演示效果代填评分。完整验收状态见 [验收清单](shengke-acceptance.md)。

## 当前试用功能补充（2026-10-12）

GPT-SoVITS 选择“舒缓语速与停顿（试用）”，CosyVoice2 开心选择“舒缓节奏（试用）”，均默认关闭。前者先保留内容生成保护，再根据本地独立识别定位可用停顿，并以 0.9 倍速处理；后者以 0.85 倍速处理。说明节奏后处理与模型情绪控制的区别，不把变慢称为情绪更强。GPT 单句获用户接受，CosyVoice 单句反馈机械感减轻。第五轮为定性意见，不应说成新增 MOS 分数。
