# ADR 0006：清单驱动的可重复 ASR 评测

- 状态：已采纳
- 日期：2026-09-24

## 背景

共享底座已经提供 Faster-Whisper 和 FunASR 适配器，但仅凭单条试听无法稳定回答模型质量、速度和资源成本。三个上层产品还需要对会议、客服、噪声音频和多语种样本使用一致口径比较。

## 决策

采用 JSONL 清单描述音频、参考文本、参考语种、可选时间戳和标签。独立 `asr_eval` 包直接复用生产 ASR 适配器，逐样本记录结果并隔离失败，聚合输出版本化 JSON 契约和 Markdown 报告。

首版指标包括 WER、CER、RTF、语种准确率、时间戳边界 MAE、进程峰值内存和 NVIDIA GPU 峰值显存。报告记录后端、模型、后端版本、平台与 Python 版本。

## 后果

- 同一清单可以用于本地、Docker 或 CI 的回归对比。
- JSON 报告可被后续排行榜和模型选型流程消费，Markdown 可直接进入评审。
- 文本规范化是语言无关基线，不替代中文分词或领域专用规范化。
- 时间戳目前按片段顺序配对；存在严重插删时，后续应升级为文本对齐后的时间戳评测。
- 真实质量数值依赖经审校数据集和实际模型权重，不写入代码仓库。
