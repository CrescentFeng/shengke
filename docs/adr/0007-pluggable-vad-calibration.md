# ADR 0007：可插拔 VAD 与标注集校准

- 状态：已采纳
- 日期：2026-09-24

## 背景

自适应能量 VAD 足以打通分段链路，但在稳态噪声、音乐、远场会议和低信噪比客服录音中容易误检或漏检。ASR、说话人分离和质量分析都依赖稳定的语音边界，因此必须在扩展下游模型前建立可替换、可量化的 VAD 层。

## 决策

在 `VadSpec` 中增加显式 backend，保留 `adaptive_energy_v1` 为兼容默认值，新增可选 `webrtc_v1`。两个后端共用采样率、帧长、短静音合并、最短语音和 padding 规则，并输出相同 `VadResult`。

新增独立 `vad_eval` 工具读取人工标注 JSONL，扫描能量阈值或 WebRTC 激进度，按重叠时长计算 Precision、Recall、F1、IoU，同时记录边界 MAE 和 RTF。仅无失败、覆盖完整数据集的候选参与最佳参数选择。

## 后果

- 在线作业可逐任务选择 VAD 后端，已有请求无需修改。
- VAD 参数变更有版本化报告支撑，不直接由离线工具写入生产配置。
- WebRTC 依赖为可选安装，不增加默认镜像体积。
- WebRTC 提供的是二元帧判断，输出置信度只能表示合并区间内的语音帧占比，不等同于校准概率。
- 后续 Silero VAD 可复用同一契约与评测框架。
