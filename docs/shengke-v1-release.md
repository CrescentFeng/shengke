# 声刻 1.0.0 · 工程验证版

2026-10-12 按本地工程型 MVP 范围收口。日常生成、历史回听下载、参考上传与质检、专业评测、四模型运行及按需后台启动构成首版；情绪强度和跨文本自然度属于后续增强，不代表已经通过全面音质验收。

## 三步使用

1. 双击项目 `scripts/启动声刻.command`。程序检查现有环境，必要时打开 Docker Desktop，然后在后台启动四模型与工作台。初次加载稍慢；看到“声刻已就绪”后可关闭启动终端。浏览器入口为 http://127.0.0.1:7860/?view=synthesis 。
2. 点“填入公开示例”，再点“生成语音”；或选择已保存音色、输入普通话短句后生成。默认 CosyVoice2、中性、原始节奏。添加个人参考时填写准确逐字稿、来源和许可，支持 3–10 秒 WAV/FLAC，最多 10 MiB。模型和节奏选项在“高级设置”中，情绪与节奏仍为试用。
3. 在“历史与下载”刷新记录，选择任务回听、下载 WAV 或 JSON 报告。时间按北京时间显示，每页 20 条。“载入参数，再次生成”只填写输入，点击生成才创建新任务；不会覆盖旧音频。固定音色基线和旧实验配置仍可回听导出，用原评测脚本复现。

专业入口包含对比试听、参考核对和评分。原 `?view=evaluation&evaluation=...` 链接仍能直达评测。21 份评分保持原样，无需再完成一轮强制评分。

## 停止与故障处理

- 双击 `scripts/停止声刻.command` 停止自有模型和工作台；数据库、MinIO、音频、评分及其他项目服务保留。`scripts/声刻运行状态.command` 查看后台实例状态。
- 重复启动会复用健康实例；另一个启动/停止进行中时提示等待。没有配置登录自动启动，也没有开启公网访问或云 GPU。
- 端口被其他程序或旧前台实例占用时，从原终端正常退出旧实例后重试；启动器不会按端口强杀进程。若“状态”显示异常，先停止再启动，诊断位于 `artifacts/shengke/service/`，模型日志位于 `artifacts/shengke/logs/stack/`。
- Docker 首次协议/权限提示由用户在应用中处理；睡眠、退出 Docker、删除模型或移动环境目录均会影响服务。启动器不会重新安装环境或静默下载权重。
- 关闭页面不会删除已提交任务；从历史可查看其状态。生成失败、被取消或断线时不显示上一份音频冒充成功。取消不能立即中断模型内部计算，迟到结果由原有作业机制丢弃。
- 参考和产物保存在本机 PostgreSQL/MinIO；没有自动删除历史。临时浏览器下载缓存不等同于正式存储，备份需同时保留数据库和 MinIO 数据卷。

## 版本与接口

声刻版本由 `configs/shengke/release.json` 单独维护，共享音频底座仍为 0.9.0。`GET /v1/tts/info` 返回声刻版本、构建哈希和运行实例标识。`GET /v1/tts/jobs?limit=20&offset=0` 只列出 TTS 作业，按创建时间及 ID 倒序，limit 范围 1–100，offset 非负。无需新增数据库表或迁移旧任务；现有生成、取消、报告和评分接口兼容。

开发仍可用 `scripts/shengke_stack.py --start-infra` 前台运行；日常入口使用 `scripts/shengke_service.py start|status|stop`，启动可附 `--open`。后台仅本机控制 socket，保留独立进程锁；所有模型以 CPU 模式运行。

## 验证与证据

最终机器可读检查：`artifacts/shengke/release-v1/final-report.json`，包含运行版本与源码哈希比对、四模型健康状态、历史和评分完整性、证据 SHA-256、已知限制。可运行：

```bash
/opt/anaconda3/envs/audio-ai/bin/python scripts/verify_shengke_release.py
```

该脚本只读取现有作业与评分并写本地验证报告，不生成音频或评分。浏览器证据包含真实合成、公开参考上传、播放、WAV/JSON 下载、参数恢复、旧评分直达；自动测试记录标明软件验证，不算真人听评。

本轮项目测试 126 项通过。平台环境跳过的 Gradio 测试模块已在专用模型环境运行 5 项通过；两项依赖 soundfile 的音频检查也已在该环境通过。数据库测试使用隔离 schema，验证后只清理自己的夹具。CPU/GPU 原基准各 144 次成功，原始音频审计已保留；本轮不重租 GPU。

## 已知限制与下一版

- 情绪控制已实现；开心强度、机械感、发音及跨文本节奏仍有限。自然语流可包含句内停顿，当前已接受样本不再列为失败。
- 四轮 21 份数字评分来自同一人；不是多人 MOS。新节奏配置仅在 Mac CPU 验证，不能套用旧 GPU 性能数字。
- VITS、Transformer 是固定音色评测基线；GPT-SoVITS 首版仅中性克隆。文本以短句普通话为主，数字和英文需写成读法。
- 本版供当前 Mac 单用户运行；不承诺其他机器开箱即用，不含多用户认证、公网生成、云端常驻或模型微调。

v1.1 再根据实际使用改进情绪、韵律和环境安装便利性。个人网站本地展示同步为 v1.0，公网部署未执行。
